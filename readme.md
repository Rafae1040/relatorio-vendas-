# 📊 Análise Global de Vendas de Consoles Meganium

## 🏢 Sobre a Empresa  
A **Meganium** é uma empresa especializada exclusivamente na **fabricação de consoles**.  
Todo o processo de **distribuição e venda dos produtos é delegado a parceiros** e plataformas terceirizadas, como **Shopee**, **Etsy** e **AliExpress**.  
Seus produtos estão disponíveis **globalmente**, sendo adquiridos por clientes de diferentes regiões do mundo.

---

## 🎯 Objetivos do Projeto  
Este projeto tem como missão **consolidar os dados de vendas provenientes de plataformas terceirizadas** e transformá-los em **insights estratégicos para a fabricante**.  
Através disso, a Meganium poderá **compreender melhor seu mercado**, **otimizar processos logísticos** e **identificar oportunidades de crescimento**.

### ✅ Metas Específicas:
- 🔗 Unificar e padronizar os dados de vendas de múltiplas plataformas (AliExpress, Etsy e Shopee).
- 📌 Analisar o desempenho por país, identificando os produtos mais populares em cada região.
- 🚚 Otimizar a logística e o transporte, oferecendo à fabricante informações que permitam melhorar os tempos e rotas de distribuição.
- 📈 Gerar indicadores de desempenho (KPIs) que auxiliem na tomada de decisão estratégica.
